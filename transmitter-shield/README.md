# AIRlert Transmitter Shield (POCSAG)

The Transmitter Shield puts AIRlert sensors onto long-range POCSAG paging, so they can raise alerts on pagers and pager-based systems with no internet. Relays and repeaters extend range on large sites. It is set up from the AIRlert app over Bluetooth.

Shields for other protocols will follow. For the shield's datasheet, wiring and pager codes for your project, email contact@frequencyprecision.com.
